# Repository instructions

Follow [prompts/repository-structure.md](prompts/repository-structure.md) before creating or moving artifacts. Update canonical files; preserve existing research and stable IDs. Avoid parallel reports, scratch folders and empty scaffolding.

For research, also follow [prompts/core.md](prompts/core.md) and the shared contract in [prompts/README.md](prompts/README.md). Keep temporary work outside the repository and run relevant existing checks before handing off.
