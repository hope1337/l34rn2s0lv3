# Competition Discovery

Input: shared contract + source inventory + existing catalog. Output: discovery records conforming to competition schema, source additions, dedup review and unresolved source backlog.

Use public organizer/platform archives first, author repositories second. Expand across CV, tabular, forecasting, NLP, speech, retrieval, multimodal, RL and Vietnamese ecosystems. Extract only explicit metadata; unknown year/track/evaluation version stays null. Preserve organizer versus sponsor versus platform. A repository index can establish existence and a code lead, not validate rules/data/final score.

Check canonical URL, aliases and identity tuple before adding. Split year × track × evaluation version. Mark practice competitions separately from finished prize competitions. Do not count a generic benchmark as a competition without shared-task evidence.

Acceptance: every entry has stable ID, traceable source and knowledge status; no duplicate identity; broad coverage gaps explicitly recorded. A JS shell or search snippet is not a verified competition description. No scores assigned in this stage.
