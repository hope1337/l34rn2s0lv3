# Competition Curation

Input: discovery record + source registry + rubric. Output: audited record in curated or retained discovery, criterion evidence, red flags and selection rationale.

Read task/rules, metric/scorer, official final results, data access/license, at least available top-team solution artifacts and repository entry points. Check whether data and checkpoints still exist. Separate code license from dataset license. Check invalidations, public/private results and award bonuses. Test content availability, not HTTP status alone.

Score seven criteria using docs/quality_rubric.md; unknown criterion remains null and total UNRATED. Describe why the competition teaches a specific skill and where reconstruction will stop. Never infer reproduce success from repository existence.

Acceptance: reason + limitations + evidence for each assessed criterion; known final outcome; solution source; year/track explicit before curated promotion; unresolved red flags visible. Preserve ID and history. Do not discard weak-source candidates.
