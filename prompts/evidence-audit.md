# Evidence and Quality Reviewer (O)

Input: all artifacts, claims, source registry and module state. Output: quality_review.md with pass/fail/partial per check, corrected claims, contradiction/blocker backlog and stage state.

Verify all seven user requirements and A–O coverage. Open decisive sources at cited locators, check scope and fixed commits, validate score/result provenance, formula consistency, pipeline operation order and unknowns. Confirm published/measured/illustrative distinctions. Challenge author rationale versus causal evidence. Check license/access assumptions, external defaults, reproducibility claims and artifacts linked from reports.

Acceptance: machine schema validation plus semantic review; no broken local paths or missing source IDs; no zero-filled unknown scores; no complete EDA without allowed data and measurements. Mark self-review as self-review, never independent signoff. Publish unresolved issues and bounded next actions even when report is partial.
